LaLaPad Gen2 RMK Firmware Flasher

ブラウザから直接 LaLaPad Gen2 (RMK) のファームウェアを書き込みます。Chrome / Edge / Opera の最新版で動作します。

このキーボードは分割キーボードで、左右で別のファームウェアが必要です。右半分 (Central) → 左半分 (Peripheral) の順に書き込んでください。

ブラウザ互換性

  • WebHID: …
  • WebSerial: …

1 ファームウェアを取得

このページに同梱された最新の DFU パッケージ (左右両方) を読み込みます。 新しい Release が公開されると自動で更新されます。

—
ローカルファイルを使う

手元の DFU zip を選択すると、それを使って書き込みます。central / peripheral それぞれ別ファイルです。

右 / Central 書き込み

右半分を USB ケーブルで PC に接続してください。 キーボードとして認識されている状態 (Vial が使える状態) なら、ボタンから DFU モードに入れます。

2 ブートローダへ入る

下のボタンを押すとキーボード選択ダイアログが出ます。LaLaPad Gen2 RMK を選ぶと自動で DFU モードに入ります。

—

うまくいかないときは、右半分のリセットボタンを素早く 2 回押して手動で DFU モードに入ってください。

3 書き込み

DFU モードに入るとシリアルポート (通常 Adafruit または Seeed で始まる名前) が現れます。

—

左 / Peripheral 書き込み

左半分は USB HID を持たないため、リセットボタンで手動で DFU モードに入れる必要があります。

2 ブートローダへ入る

左半分を USB ケーブルで PC に接続したあと、リセットボタンを素早く 2 回押してください。 シリアルポートとして列挙されれば DFU モードに入っています。

3 書き込み

下のボタンでシリアルポート (通常 Adafruit または Seeed で始まる名前) を選んでください。

—
